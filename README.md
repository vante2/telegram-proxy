# 🚀 Telemt Auto — MTProxy для Telegram

Автоматическая установка **MTProxy с TLS-маскировкой** на твой VPS.
Одна команда — и приватный прокси готов.

## ✨ Особенности

- 🔐 **Маскировка под любой сайт** — трафик выглядит как обычный HTTPS
- 🤖 **Полная автоматизация** — скрипт сам ставит Docker, генерирует ключи, запускает
- 🌍 **Автоопределение IP** — не нужно вводить адрес сервера вручную
- 🔄 **Автозапуск** — прокси переживёт перезагрузку сервера
- 💾 **Ссылка сохраняется** — не нужно запоминать секрет, он в файле на сервере
